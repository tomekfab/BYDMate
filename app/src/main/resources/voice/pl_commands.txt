# BYDMate built-in voice commands, Polish.
#
# The Polish command dictionary keeps the same categories and dispatch strings as the vehicle protocol.
# number ranges and rounding. A phrase runs offline only when it equals one phrase of this file, word
# for word. Anything else never runs; a request to the car that matches nothing is refused (see
# NluParser.classify), a harmless phrase may go to the assistant when the user enabled it.
# "A i B", "A oraz B", "A a także B", "A potem B" and "A i potem B" run when every part is a
# parameter command of this file on its own; a part that is a step, a question, navigation or the
# volume never takes part, and the whole utterance is refused.
# "czy możesz ..." / "chciałbym ..." are dropped only at the very start (VoiceTextRules.words).
#
# Both the phrase and the template words are normalized the same way (PolishVoiceNormalizer): lower
# case, punctuation out, "%" -> "procent", number words -> digits ("dwadzieścia dwa" -> 22).
# Diacritics are kept, never folded: an unaccented spelling works only where it is written out below.
# Filler words (proszę, mi, możesz, słuchaj, hej, ej, dziękuję, chcę, ja) are dropped from the phrase.
# Neither they nor a negation (nie, ani, bez, nigdy, przestań) nor a quote marker (powiedział,
# polecenie, ...) may appear here, so a phrase that holds one can never equal a template.
#
# Format notes and deliberate Polish grammar differences:
#   - "światło"/"światła" alone is the headlights in Polish, which are not supported: the interior
#     light needs "w kabinie"/"w środku"/... and the daytime running lights need "dzienne"/"drl".
#   - Verbless phrases are standalone here ("klimatyzacja auto",
#     "temperatura 22 stopnie").
#   - A postposed verb is accepted only in the listed windows/sunroof forms ("szybę pasażera
#     zamknij", "do połowy otwórz okno"); there are no colloquial vent-window forms.
# Each template phrase has a matching row in app/src/test/resources/voice/pl_commands_golden.tsv.
