How to restore the widget

open BYDMate
• Tap the BYDMate icon on the DiLink home screen
• The app opens → the widget returns automatically to its saved position
• Close BYDMate → the widget floats above again
— no buttons or permissions — just open the app
Widget layout:
Size: 260 × 108 dp, padding 8×14 dp, border 1.5 dp, corner 14 dp.
Row 1 — ⏱ 22 min · 🚗 25° (13sp mono). Icons grey, values white.
Row 2 (centre) — 78% 18sp bold (SOC colour) · ~352 km 28sp bold white · ↓ 14.8 18sp (trend colour).
Row 3 — 🔋 28° · ⚡ 12.7 V. Same style as row 1.
Separators — 1dp line alpha 0.22.
Icons: Material Outlined — Schedule, DirectionsCar, Battery6Bar, Bolt, TrendingDown/Flat/Up.

Touch behaviour:
• Normal tap → open BYDMate (as now).
• Drag → move the widget; dropping it in the bottom-centre “trash” zone disables it completely (settings flag).
• Long-press 1500 ms → hide until the next BYDMate opening. Highlight during the press; toast after activation.

Long-press technical implementation:
• In WidgetTouchListener, add a Handler with a 1500 ms delay in ACTION_DOWN; cancel it in ACTION_MOVE (if the threshold is exceeded) and ACTION_UP.
• On activation: WidgetPreferences.setHiddenUntilAppLaunch(true), WidgetController.detach(), Toast.makeText(...).
• In BYDMateApp.WidgetLifecycleCallbacks.onActivityResumed, reset the flag to false (the widget returns automatically when the Activity enters pause — standard background attach logic).
• In WidgetController.attach, add an early return if hiddenUntilAppLaunch == true.
