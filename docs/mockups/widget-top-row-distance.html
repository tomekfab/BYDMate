Slots have equal width (CSS grid 1fr 1fr 1fr) with start / center / end alignment respectively.
Time switches to a compact hour format: 25 min / 1 h 25 min, so a long trip does not overlap the centre slot.

Changes in FloatingWidgetView.kt:
1. RowTrip(sessionStartedAt, tripDistanceKm, insideTemp) — add the new parameter tripDistanceKm: Double?.
2. Inside RowTrip: replace Row(SpaceBetween) to Row with three Modifier.weight(1f)-columns, each — Box(contentAlignment = Start / Center / End).
3. Centre: IconText(icon = Icons.Outlined.Route, text = formatTripKm(tripDistanceKm)).
4. formatTripKm: null → "—"; x < 10 → "%.1f km".format(x); x ≥ 10 → "%.0f km".format(x).
5. formatDurationShort: minutes — "$minutes min"; hours — "${hours}h ${minutes}min" (short format).

Data source:
In TrackingService add val _tripDistanceKm = MutableStateFlow<Double?>(null) → public val tripDistanceKm: StateFlow<Double?>. It updates in the polling loop from tripTracker.distanceKm (already calculated for BD). In WidgetController.attach() collect this Flow and pass it to FloatingWidgetView.
If the session is closed (ignition-off): distance null → the widget shows —.

Distance icon: Icons.Outlined.Route (Material Outlined) — two points joined by a winding line. It is visually distinct from Schedule (clock) and DirectionsCar (car).

Time format — compactness rationale:
Current "1 h 25 min" = 10 monospace characters 13sp ≈ 80dp. In the three-slot grid, a 77dp slot is too small.
Compact "1 h 25 min" = 6 characters ≈ 48dp → remaining space 29dp for the icon and spacer.
I do not change the format in the TrackingService notification because there is ample space.
